# Expression Validator and Prefix Evaluator

> Supporting — Algorithms · Birzeit University Computer Engineering portfolio

A menu-driven C program that validates mathematical expressions, converts them to prefix notation, and evaluates them using stacks.

## What this demonstrates

- C
- stacks
- parsing
- expression evaluation
- file I/O

## Repository contents

The implementation is in `P2_1212359_NouraManassra_Section5.c`; sample input and output are included.
